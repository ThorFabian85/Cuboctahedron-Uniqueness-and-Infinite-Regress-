DEMU — A question of balance
Website by Thor Fabian Pettersen, with analysis and presentation by ChatGPT.

OPEN THE WEBSITE
1. Extract all files from this ZIP into a folder.
2. Double-click index.html to open the website in your browser.
Keep index.html, styles.css, app.js, and the papers folder together.

EDIT THE WEBSITE
Edit index.html for content, styles.css for appearance, and app.js for the
interactive cuboctahedron. No installation or build step is required.

PUBLISH ELSEWHERE
Upload the extracted website files to a static website host, keeping index.html
at the root of the published folder and preserving the papers folder.

INCLUDED PAPERS
- Cuboctahedron Uniqueness and Infinite Regress (PDF and Word)
- Timeless Balance and Infinite Regress (PDF and Word)

The site presents a philosophical proposal, conditional mathematical results,
and the remaining work. It does not claim a completed proof of the full
metaphysical uniqueness argument.

UPDATED VIEWER
Hold the left mouse button and drag to rotate in any direction. Use + and -
to zoom, Reset to restore the view, and Expand view for an immersive viewer.
Arrow keys rotate when the diagram has keyboard focus; Home resets it.

ADDED DOWNLOADS
All twelve supplied PDFs are included. The seven earlier-solution documents
have their own section, My old solution — worth saving.

VECTORS ONLY
Click Vectors only to hide the outer faces and edges and see the twelve radial
vectors. Click it again to restore the previous geometry view.
